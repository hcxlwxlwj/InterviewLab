# 2026-10-19：课程模板对齐与代码职责整理

## 背景与决定

用户要求参考 [IntelligentSWEPractice](https://github.com/bettermorn/IntelligentSWEPractice) 整理现有代码与文档。现有顶层目录已满足课程要求，主要问题是核心文件混合类型、合成数据与规则，个人中心包含五个分区，文档仍将已存在的原型写为尚未实现。

保留课程指定目录、现有 UI、URL、历史材料快照及旧文档导航；按实际职责拆分，不引入尚无实现的数据库、网关或 Agent 服务。

## 完成的整理

- 核心分为领域类型、端口、配置、出题、会话、分数汇总和知识纯函数；不再读取岗位 JSON。
- 新增公开内容适配工作区，复用现有版本化 JSON；合成简历、会话和固定演示报告通过独立 `/demo` 入口导出。
- 后端拆开请求校验、HTTP 响应、路由、接口清单及服务合同。
- 前端个人中心拆为五个分区、共用框架/表格和控制器；演示存储拆为状态迁移、简历、收藏/JD、客户端组合及校验。
- 重写根 README，增加代码/测试导航与各包说明；更新当前架构、接口及模块状态，保留历史复盘记录。
- 增加依赖边界检查与 CI 步骤，以及统一检查、代码格式命令和编辑器格式约定。

## 验证记录

类型检查、依赖边界、内容检查及 35 项规则/接口测试已通过。新增规则验证显式传入的模板快照不会被全局题库替代。36 个模板、288 道问题、72 条来源没有改写。

生产构建与文档链接检查通过。依赖检查另做负向验证：临时在核心导入 Node 文件 API，检查如期失败；移除探针后恢复通过。开启 `noUnusedLocals` 防止拆分后残留未使用绑定。

使用独立临时浏览器标签页完成：复制简历 → 编辑保存 → 收藏 AI 产品岗位 → 复制个人 JD / 关联简历 → 刷新恢复 → 携带配置 → 专业问答 → 提交 / 暂停 / 恢复 / 跳过 / 结束 → 报告 → 单题重练 → 原新回答对照 → 记录回看。五个个人中心分区及旧 `/me?tab=records` 均正常，浏览器未记录 warning/error。全程使用虚构材料，未修改用户已有标签页数据。
