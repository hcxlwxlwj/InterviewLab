核心任务是围绕学生项目经历开展实时口头模拟面试，使学生练习临场组织和连续追问；面后将回答内容、语音节奏和可选镜头表现定位到具体片段，再定向重练。默认实时语音，文本为降级与联调过渡入口。语音与视觉观察独立于四维能力评分，不推断情绪、诚实、人格或能力。与现有产品及认真提示的通用模型开展后续对照，明确实时口语与可编辑文本的条件差别，不预设优胜；未开展真实访谈或效果实验。

后续实现按课程职责将纯逻辑放入 code/core_engine，数据库、文件及供应商 I/O 放入业务或适配层。当前没有运行代码。
