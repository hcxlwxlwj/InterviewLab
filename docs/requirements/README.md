# 需求与问题定义

版本：v0.2 · 日期：2026-10-15 · 状态：当前设计，尚未实现。

本目录按课程要求集中维护需求正文。当前定位是面向实习经历有限、主要拥有校园项目等经历的高校学生，优先技术岗位；以实时口头模拟、面后内容与表达复盘、针对性重练为主线。默认 `realtime_voice`，`text_fallback` 可独立完成，报告注明作答方式；不设置教学前置流程。

阶段 A 为基础闭环与文本联调（过渡），阶段 B 为实时语音与基础多模态（首版核心），阶段 C 为评测试用。实时作答自动判断回合结束并保存、自然接续，允许思考、自纠、澄清、用户打断和误截恢复；面试中不展示参考答案或能力评分。

FR-04 教学模式与 FR-07 的 3D 必需要求已退出范围，保留编号追溯；FR-14 为独立语音观测，FR-17 为可选镜头与问题片段复盘。语音/视觉观测不计入四维总分，不推断情绪、诚实、人格或能力；摄像头默认关闭，原始音视频默认临时处理后清除，仅明确开启复盘媒体保存时私有保留、自采集起最长 24 小时。合成例不是访谈或实测，产品设计重点与实际效果均待验证。
