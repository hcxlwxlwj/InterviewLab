# 非功能需求规格

版本：v0.3 · 更新：2026-10-19 · 状态：设计目标，待实现、待测量。

## 1. 使用方式

以下编号沿用 v0.1，新增项追加编号；历史要求变更由 Git 与变更记录追溯。阶段 A 为基础闭环与文本联调（过渡），B 为实时语音与基础多模态（首版核心），C 为评测试用。默认 `configuration.interaction_mode=realtime_voice`，`text_fallback` 可独立完成并标明作答方式。性能数字只有测量后才能写为达成结果，服务商、预算与部署配置尚未确定。

| NFR-09 一致性与任务可靠性 | 自动保存有可见状态，完整语音回合或提交文本保存后才计入报告；幂等写入、删除标记及输入版本在任务发布前复核。误截恢复、ASR 纠错使依赖结果失效；陈旧报告不得显示为当前结论 | 断线重连、重复任务、追加/纠错与生成并发、删除与重试竞态，确保取消代不播放或覆盖新代 |

## 2. 保存、删除与最少采集

- **简历库：**`library` 文件及其版本私有保存至用户主动删除，不适用临时上传 24 小时自动清理。下载及预览也要鉴权。
- **临时上传：**`temporary` 默认不入库，文件和提取稿自上传起最长 24 小时，可主动保存入库。清理临时文件不默默撤销已确认经历或历史会话快照。
- **原始音视频：**默认仅临时处理后清除，不长期持久化；结束、取消或断线时丢弃不再必要的临时缓冲。仅用户明确开启 `review_media_enabled` 才可私有保存复盘媒体，自采集起最长 24 小时，并显示可用截止时间，重连或报告重试不重置；未保存/到期后回放和依赖原媒体的重算不可用，不生成替代片段。派生观测、时间戳及版本依个人记录策略保存，和原始媒体生命周期分开。
- **摄像头：**`camera_enabled=false` 为默认，可拒绝或中途关闭；关闭即停止采集并清除不再必要的临时缓冲，不补算关闭区间。无需人脸身份识别，不采集与观测无关内容。开启摄像头不自动开启复盘媒体保存。
- **采集开始：**默认 `realtime_voice` 只是配置，不自动开启麦克风；明确点击开始并完成浏览器授权后才采集。面试中仅显示设备质量、连接和保存等运行信息，表达反馈与点评在面后集中开放。
- **个人记录：**确认经历、回答、会话快照、报告、代码和比较保存至用户删除。删除简历文件/提取稿保留独立确认经历并解除来源关联；删除经历或会话另行说明级联影响并确认。对受影响数据立即停止访问、失效相关任务，再按已公开窗口清理；备份不能把已删除数据重新上线。
- **外部调用：**仅发送本次必要字段，模型不能取得维护权限；上传限制、清理时间、备份窗口和删除依赖以[数据与接口](../software/data_and_interfaces.md)为唯一细则，试用前核验供应商处理条件。

原文件删除与到期、经历删除及会话删除是不同动作，界面须解释各自影响。开发与评测只用合成或明确获授权材料，不将真实个人简历、音视频和密钥提交到仓库。

## 3. 评价及执行边界

评分依照[功能需求](functional_spec.md)的四维百分制，未观察为 `score:null` 与 `not_observed`；总分按已观察维度等权平均四舍五入，零有效回答不评分。可观察到的错误回答可评分，跳过或未考查不能自动记零。报告应区分技术理解、本人职责未讲清与表达组织问题。

语速、停顿、疑似口头语、音量和音高变化只描述观测，不诊断情绪或判定人格、诚实与能力。可选视觉仅描述可核对面部动作、头部朝向和画面质量；不能把看向镜头外等同缺少眼神交流，也不能把面部动作命名为紧张或自信的事实。文本作答、音视频不足、识别不可靠或摄像头关闭时说明不可观测，不捏造指标。语音/视觉观测独立于四维总分；内容和表达同时发生不证明因果。

默认实时方式允许思考、口头自纠、澄清和打断 AI；不通过强迫快答形成虚假压力。AI 主动打断仅作为可选风格。ASR 面后纠错必须保留原识别、修订原因与版本，不能通过润色或补充知识改写为原始口头回答；识别误差导致的反馈应失效或重算，并说明依赖媒体是否仍可用。

代码执行使用隔离服务，约束时间、内存、网络及文件访问；不可在应用主进程执行学生代码。运行结果与 Agent 评审分开，禁止把模拟输出当真实证据。代码资源上限由执行服务配置及模块文档确定，不由生成文本修改。

## 4. 验证与发布门槛

| 阶段 | 非功能门槛 |
| --- | --- |
| A 基础闭环与文本联调（过渡） | 无材料路径、保存/恢复、引用与版本、跨账号隔离、删除/任务竞态、四维评分规则和原型标注可验收；可选代码若真实运行须满足隔离要求；不据此宣布首版实时体验完成 |
| B 实时语音与基础多模态（首版核心） | 自动回合保存、自然接续、思考/澄清/打断/误截恢复、文本降级、面后纠错、迟到帧处理、语音/可选视觉观测依据、默认最少采集与显式媒体保存策略通过；记录分段延迟/回合错误和失败率，拒绝摄像头不阻断 |
| C 评测试用 | 供应商处理条件、实际费用、授权材料和人工评价方案核验后开展；记录负面结果及不确定性 |

测量口径、样本和具体门槛集中在[评测与迭代](../algorithm/evaluation.md)。不以注册数、满意度或模型分数独立宣称学习有效，不预设本系统胜过竞品。文档交付检查包括引用可达、需求到页面及接口可追踪、旧需求不再作为当前要求以及 `git diff --check`。

## 5. 按使用场景补充的约束

以下约束整合自原功能说明，接口细节以[数据与接口](../software/data_and_interfaces.md)为准。

### 简历与确认经历

默认文件上限 10 MiB，只接收有文本层 PDF/DOCX。服务端同时校验扩展名、实际类型、压缩展开体积与解析结果；拒绝密码、损坏或异常压缩文件。解析/预览使用受限任务，不执行宏、脚本、嵌入对象或外链。OCR 为后续扩展，扫描件给手填入口，不从空文本猜经历。

LLM 候选须有存在于提取文本中的来源；数字保留单位与原措辞，模糊职责标待澄清。用户确认时保存内容、时间与版本，模型/解析重试不能覆盖用户修改；重复确认使用幂等键避免重复经历。Agent 的事实读取 Tool 只拿本次选中的已确认字段，默认不发送联系方式。

上传材料、代码片段和原文中的指令视为资料，不获得读写工具权限。每次预览、下载、详情、经历读取检查归属，私有存储不提供可猜测的公开地址。

文件删除清除原文件、草稿、预览及缓存，保留独立确认经历并解除源文件引用，入口须说明。若学生要删除经历事实，先列相关会话、报告、比较及快照影响，再级联清理。删除标记即时禁止访问，异步任务提交前再次检查，防止解析迟到复活材料。

### 内容维护与运行管理

发布内容和索引存 PostgreSQL/pgvector，切分与嵌入由持久 job 执行。岗位/主题/发布状态过滤先限定候选，再检索；来源定位不因向量化丢失。嵌入模型变更需重建可切换索引并抽检，不混用不兼容向量。知识中的指令视为资料，不能成为系统/工具命令。

运行指标包括材料解析、回答自动封存到首段文本、语音端点到可播放、误截/恢复、打断停止、媒体质量/到期清理、会话完成、报告/比较/导出成功、代码队列/执行、取消与费用。每项标时间范围、分母与数据缺口；学生主动结束、主动取消、网络中断、供应商失败、程序故障分别计数。未知用量/价格标未知，不能当零成本。

持久任务采用唯一任务键、领取锁、超时租约与状态检查；外部请求只在预算允许且无成功结果时至多有界重试一次。解析/报告结果提交前复核输入版本和删除状态，防止重试覆盖学生修改、过期评分或复活已删对象。代码任务取消同时终止隔离进程，费用/资源限额在服务端执行。

日志保留脱敏请求、会话/任务标识、阶段、版本、耗时、用量、错误和操作审计，不写完整简历、逐字稿、报告、私有提示或密钥。服务商密钥仅服务端配置；变更服务或密钥后用合成冒烟样例验证。

### 可选代码考核

Web/网关只保存输入并通过适配器请求隔离执行服务，不能在应用主进程或数据库主机直接运行用户代码。每个任务使用隔离实例、只读基础环境和限额临时目录，禁止访问宿主敏感文件及未经许可网络，限制编译/运行时间、CPU、内存、进程、输出和文件大小。具体阈值由经验证的配置版本提供，客户端和模型不能放宽。

任务唯一键关联提交 revision、测试版本与任务类型，重复运行请求不重复创建同一结果。题干、输入输出、编译错误、代码注释均为不可信资料，不能触发外部工具、SQL 或任意网络调用。自定义输入同样受长度/输出与资源限制。

结束/暂停/取消按活动任务规则请求停止，隔离执行器终止进程并清理临时目录；迟到结果可保留为对应已保存提交的运行记录，但不能覆盖新版代码、触发已结束会话追问或改变终态。报告只取封存输入版本并核对有效性。

尚未接入真实执行器时，运行按钮显示能力不可用并可继续文本/静态评审；未来原型可以显式模拟数据演示，必须让模拟标记在面板和报告中可见，不能将它当真实测试证据。

### 个人中心

library简历私有保存至主动删除，temporary自上传起最长24小时，原音视频默认临时处理后清除。显式开启的私有复盘媒体自采集起最长24小时，可提前删除；确认经历、原作答轨迹/识别纠错、会话、代码、派生观测与报告保存至主动删除。列表显示文件/媒体到期或已清理状态，报告时间定位不保证仍能回放。

删除文件清理文件/提取稿/缓存，保留独立确认经历并解除源引用，入口明确说明；删除经历则先列关联会话/报告/比较等影响，再按经历级联清理私有快照。删除会话删除其原作答/纠错、报告、导出、代码、音视频观测、复盘媒体与相关比较；重练独立回答按公共规则处理，不保留已删来源全文。单独删除媒体立即撤销播放，已产生派生观测是否保留在操作入口说明。

在线访问撤销立即生效，物理清理目标 24 小时内；限权备份轮换最长 30 天，恢复须重放删除清单。清理任务显示实际状态，不把“已提交删除”说成全部备份瞬间抹除。所有期限仍是待实现设计默认。
