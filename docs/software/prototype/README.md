# 六界面单元与交互原型说明

版本：v0.3 · 日期：2026-10-19 · 状态：下文保留完整产品规格；本轮已实现高保真演示子集，实际边界见[首轮实现说明](implementation.md)。

## 1. 体验目标与信息架构

面向实习经历有限、主要拥有课程项目、竞赛、科研或毕设经历的高校学生，优先计算机技术岗位。学生直接进行实时口头模拟，练习临场组织和连续追问；面后分析回答、语音节奏与可选镜头表现，再针对一个缺口重练。不增加教学课程或完整材料整理的前置流程。

六个界面单元由五个主路由加一个嵌入代码工作区组成，不要求六个独立路由：

| 编号 | 界面 | 拟议路由或承载 |
| --- | --- | --- |
| UI-01 | 首页 / 欢迎页 | / |
| UI-02 | 面试配置 | /interview/setup |
| UI-03 | 面试主会话 | /interview/{session_id} |
| UI-04 | 代码答题面板 | UI-03 内嵌，可展开为弹窗 |
| UI-05 | 分析报告 | /reports/{session_id} |
| UI-06 | 个人中心 | /me 概览及 resumes / interviews / saved-jobs / preferences 分区 |

路线：UI-01 → UI-02 → UI-03（按需打开 UI-04）→ UI-05。UI-06 可选简历后返回 UI-02，也可从记录回到 UI-03 或 UI-05。报告的重练入口创建关联模拟会话并复用 UI-03，完成后在 UI-05 显示比较。

## 2. 首页与配置

### UI-01 首页

介绍“讲清自己的项目和优势”的使用场景，而非保证拿到 Offer。提供前端、后端、算法、测试等岗位，难度及技术问答、项目深挖、HR、综合面试类型。开始按钮携带选择进入配置；查看记录进入个人中心，帮助说明采集、评分范围和故障替代方式。首页不重复上传简历或要求完成学习课程。

### UI-02 配置

确认JD/岗位模板、5或10分钟（默认10）、面试官风格、是否代码考核；交互默认realtime_voice，text_fallback可独立完成。实时口头回答自动判回合结束，不编辑转写后发送。评分与表达反馈固定在结束后；最多6主问题、各2追问，12分钟安全上限含暂停，开始前说明。

设备区检查麦克风和播报；点击开始并当场授权后才采集。可选摄像头默认关闭；私有复盘媒体保存也默认关闭，须分别授权音频/视频，明确自采集起最长24小时及提前删除。无需摄像头/媒体保存仍可完成面试，低质量不影响专业分。

简历选择区域展示库内已上传文件的名称、版本、解析状态和默认标记。默认选中库内已确认简历；其他状态可以核对、等待、重试或跳过，不把上传即视为可用事实。临时上传默认不入库，明确显示最长 24 小时及“保存到简历库”动作。

重点经历区域只显示所选简历关联的已确认经历，以及学生明确另选的手填经历；切换简历后清除不再属于该选择的重点，需重新确认。字段可轻量补充本人职责、技术选择、结果和材料依据，不要求整仓上传。无简历或无可用项目时可进入岗位通用问答；相关维度后续标记未观察。

开始前显示岗位、简历版本、重点经历、时长和代码开关摘要。开始动作校验版本并冻结快照；材料变更须先确认，重复点击不得创建两场面试。开始后换材料或类型需新会话。

## 3. 面试与代码

### UI-03 双栏主会话

桌面左侧约35%展示面试官、当前问题、问题历史和播报状态；右侧约65%为学生实时作答与对话记录，代码题时承载代码面板。可选镜头仅为小预览，不设置常驻第三个评分侧栏。

顶部工具条集中显示岗位、经过时间、当前第 n 个主问题 / 最多 6 个、当前追问序号，以及暂停、跳过、结束。主问题进度不把追问算成额外固定题目；暂停仍计入总资源时长。

面试官状态区分提问中、播报中、等待回答、识别中和思考中。学生可停止播报或打断；迟到的旧代文本/音频不重新进入界面。默认不显示大幅3D人物或摄像头区。运行设置可切文本、关闭镜头或撤回媒体保存，经interaction-settings服务记录版本与事件；关闭立即停对应采集/写入，重新授权只处理后续片段，不延长已有媒体期限。

学生听题、思考后直接说，字幕显示原始识别；端点确认后自动保存并自然接话，不提供转写润色发送。短暂停顿保留等待，学生可口头自纠、澄清、打断AI；误截提供“继续回答”口头追加，保留原轨迹并取消过早追问。AI主动打断仅可选风格。麦克风/ASR失败保留已保存片段、标采集缺口并切text_fallback，文字可独立完成且明确标注。

模拟期间只提问、追问或澄清题意，界面与API均不开放参考答案、答题框架、表达点评或能力分；仅显示采集/连接质量与处理状态。跳过记录为跳过，不伪造回答。结束时停止音视频，封存已保存回答及带缺口的可用片段，未完成片段不能静默当完整有效回答评分；text_fallback草稿提供提交/放弃/返回，未提交草稿不纳入评分。

### UI-04 代码面板

支持C++/Python/Java语法高亮，按题目初始化模板。代码允许编辑草稿、运行和正式提交，此规则独立于口头答案不可润色替换。显示题干、用例输入、期望输出、stdout/stderr、实际输出和结果；仅运行不等于正式提交。

状态至少包括未运行、排队、运行中、完成、编译失败、运行失败、超时和服务不可用。切换语言前提示保存各语言草稿；旧任务结果关联其代码版本，不覆盖新代码。提交结果与 Agent 评审分别标注状态，不能因模型说正确就显示测试通过。

面试中可追问思路，完整错误分析与参考解法在结束后报告展示。代码不开启时不占作答区域，代码能力维度标记未观察。未来 Mock 原型的结果显著标注“演示结果，未真实执行”，真实运行必须接隔离执行服务。

## 4. 报告与个人中心

### UI-05 分析报告

结束后自动进入报告生成状态，显示“回答已保存，正在生成分析”。支持离开后从记录回来；失败只重试报告，不重新跑面试。中断会话有已保存回答可生成部分报告，注明范围；零有效回答只展示记录和重新开始入口，不生成得分。

桌面采用左侧约60%逐题复盘区与右侧约40%突出数据区。右侧展示总分、已观察维度/覆盖范围、四维评分和独立语音/可选镜头观测。雷达图不将未观察值绘成0，同时提供文本/条形数值。小屏先显示摘要与覆盖，再显示逐题内容和观测。

逐题内容包括问题与追问、原作答/口头自纠/误截追加、识别纠错版本、点评引用、参考要点和片段重练入口。面后仅可更正ASR识别错误，保留原识别、原因和revision，不能润色替换原话。项目分析聚焦本人贡献、技术取舍、结果依据、岗位关联；区分没讲到与技术错误，没有商业收益或实习不自动判低能力。

优势卡片列出支持它的回答或材料；参考表达仅基于确认事实，缺少结果提示补充。独立表达区展示语速、停顿、疑似口头语、音量/音高变化及可选画面质量/头部朝向/面部动作，关联回答时间片段和质量。低置信、纯文本、未开镜头或媒体失败显示空态，不记零分，不推断情绪、诚实、人格或技术能力。默认无原始媒体回放；显式保存仍须有效授权和未过期，时间定位与可回放状态分开。

操作包括重练此题、重新面试、导出 PDF、查看记录。记录已自动保存，取消意义不明的“保存记录”按钮。PDF 包含覆盖范围、证据与部分报告标记；生成失败允许重试，不导出未校验的半份报告。

重练比较展示选定问题、原/新回答版本及片段、目标和变化依据。不同题意/材料/标准标明限制；输入模式不同时不可直接比较语音变化，不能仅用总分差宣称进步。自动同类新题推荐后续实现。

### UI-06 个人中心

记录 Tab：展示岗位、类型、开始时间、会话状态、报告状态、覆盖范围和可用总分。未完成记录进入继续面试；已完成但报告未就绪进入生成态；失败有回答可查看部分报告；无回答不显示 0 分。支持筛选、删除及清理状态，不将失败冒充完成。

简历 Tab：上传 PDF/DOCX、多份命名、预览、下载、设默认、删除和确认内容。默认仅库内已确认简历。临时上传可显式转入库；文件删除说明独立确认经历仍保留，删除经历另列会话/报告/比较的关联影响。历史会话保持当时快照，不随简历编辑漂移。

偏好Tab：默认交互方式（初值实时语音）、编辑器主题、默认岗位方向。偏好只影响新配置；镜头与复盘媒体每场默认关闭。记录显示实际输入模式、媒体到期/删除和观测质量，无可用语音时文本可独立继续。

## 5. 状态与验收对照

| 场景 | 预期行为 | 关联模块 |
| --- | --- | --- |
| 选简历后切换另一个版本 | 重新确认重点经历及材料摘要 | [个人材料](../../requirements/functional_spec.md#feature-materials)、[配置](../../requirements/functional_spec.md#feature-configuration) |
| 不上传简历或解析失败 | 提供手填或岗位通用问答 | [配置](../../requirements/functional_spec.md#feature-configuration) |
| 拒绝麦克风、识别失败、播报失败 | 文本可继续，不丢已保存回答 | [语音](../../requirements/functional_spec.md#feature-speech) |
| 思考、口头自纠、误截续答 | 端点不急切截断，追加到原回合并保留事件 | [语音](../../requirements/functional_spec.md#feature-speech) |
| 关闭镜头、遮挡、媒体到期/删除 | 不扣专业分；低质量不可用，过期不伪造回放 | [语音](../../requirements/functional_spec.md#feature-speech) |
| 暂停、重连、取消旧输出 | 权威状态恢复，不重计回合或重置时长 | [模拟](../../requirements/functional_spec.md#feature-interview) |
| 无代码题、跳题、零回答、部分报告 | 未观察/范围标记正确，无虚假零分 | [报告](../../requirements/functional_spec.md#feature-report) |
| 只运行代码或运行失败 | 不冒充正式提交或正确答案 | [代码](../../requirements/functional_spec.md#feature-code-assessment) |
| 重练和删除来源 | 明确对照版本，关联清理和失效提示 | [重练](../../requirements/functional_spec.md#feature-retry) |

所有主要操作支持键盘、清晰焦点与可读状态，图表提供文本替代。原型使用合成材料并区分演示与真实检测，不能用界面状态替代真实能力验收。公共定义以[数据与接口](../data_and_interfaces.md)为准，需求追溯见[用户故事](../../requirements/user_stories.md)。
