# 05｜双栏模拟面试

版本：v0.2 · 日期：2026-10-15 · 状态：待实现、待验证。

## 1. 目标与交互

围绕学生确认的课程项目、比赛、科研、毕设或实习进行连续提问，让学生独立解释个人贡献、技术决策、结果依据及岗位关联。系统 mode 仅 mock，进行中不提供答题框架、参考答案或逐题评分；学生可以澄清题意、重复、跳过、暂停和结束。

会话采用双栏空间：左栏为 AI 面试官状态、当前题与提问轨迹，右栏为学生实时回答和可展开代码编辑器。采用静态/简化面试官呈现，不要求真人视频或 3D；可选镜头为小预览。顶部/辅助区显示岗位、时间、主问题号与当前追问号及控制按钮，进行中不展示参考回答、表达点评或能力分。

每次只有一个待回答问题。默认实时口头作答：学生思考后直接说，端点确认自动保存原识别和片段轨迹，再自然生成追问/下一题；不编辑转写后发送。允许口头自纠、澄清、打断AI和误截后的口头追加。text_fallback 可独立完成并标注模式。退出后可在个人中心找到未完成记录继续；会话结束转到报告生成状态页，ready 后展示分析。

## 2. 数据、预算与状态

开始事务冻结岗位、简历及重点经历版本，连同题库、标准、提示及模型版本保存。核心 `Session`、`Turn`、`AnswerSegment` 和状态以[数据与接口](../data_and_interfaces.md)为准；ASR 原识别、片段轨迹、面后识别纠错、完整问题和实际呈现/播放范围分开，不能润色替换原话。

| 约束 | 首版行为 |
| --- | --- |
| 时长 | 5 或 10 分钟，默认 10；目标时间提示收尾，不即时截断回答 |
| 安全上限 | 自start起12分钟总经过时间，包含暂停和断线；取消生成/采集，封存已保存内容及带缺口片段，未完成片段不静默当完整回答评分 |
| 题量 | 最多 6 主问题、各最多 2 追问；显示主问题号和追问号，不伪称固定总题数 |
| 终态 | completed 不重开；failed 不改 completed，可对已保存回答请求部分报告 |
| 输入恢复/纠错 | 误截口头追加产生新revision并取消过早追问；面后仅ASR识别纠错，新revision使报告/比较/对齐过期 |

编排器控制 `draft/ready/in_progress/paused/ending/completed/failed`。暂停停止录音、生成及播放，不冻结 12 分钟安全时钟。可恢复服务故障优先转文本或有界重试，不立即把会话标 failed。

## 3. 提问与处理策略

根据 interview_type、JD 与本次经历建立问题覆盖表，主问题可来自发布题库并按材料改写。项目深挖优先问本人负责模块、技术选型、具体困难、实验/测试及协作；技术问答和 HR 面仍遵守材料边界。无材料使用通用题，不假装了解学生项目。

每次已保存回答后记录已回答信息与缺口，优先追问尚未说明的个人行动、技术原因或结果依据。已补充信息不反复追问，学生没有做过的事项可以询问理解或设想，但不变成“你曾独立完成”的前提。课设可用功能、实验、测试和产物说明结果，不强求商业收益或线上规模。

LLM 返回问题文本、目的、关联回答证据与建议动作，程序检查事实、题意重复、主/追问数量和剩余时间后执行。动作失败保留原已保存回答，不能重复保存或让模型自行放宽预算。澄清只解释题目所问，不暗示正确答案。

文本/语音共用提交与状态服务；端点候选可因继续说话撤销，短暂停顿不能直接判答完。`generation_id` 标识生成代；打断先停止本地队列，再取消服务端代，丢弃迟到文本/音频。AI主动打断仅可选风格。问题从未展示且未播放时不计已问；重连读取权威会话、已保存回合与时间预算，不自动重放全部帧，媒体缺口如实记录。

## 4. 接口与依赖

| `/api/v1` 接口 | 职责 |
| --- | --- |
| `POST /sessions`、`GET/PATCH /sessions/{id}` | 创建/查询配置与权威状态；PATCH 只用于未开始配置 |
| `POST /sessions/{id}/start`、`/pause`、`/resume` | 状态、归属、版本、预算控制 |
| `PATCH /sessions/{id}/interaction-settings` | 实际输入模式切换、镜头/媒体保存分别授权或撤回，记录版本与事件；不改变原材料与时长 |
| `POST /sessions/{id}/turns` | answer/clarify_question/repeat_question/skip，确认和幂等保存 |
| `PATCH /sessions/{id}/turns/{turn_id}` | 面后仅ASR识别纠错，保留原文/原因及依赖失效，拒绝润色 |
| `POST /sessions/{id}/turns/{turn_id}/append` | 活动回合误截后的口头续答，保留片段及恢复事件 |
| `POST /sessions/{id}/finish` | 幂等取消、封存与异步报告 |
| `GET /sessions/{id}/report`、`POST /sessions/{id}/report/retry` | 当前状态、失败/部分/过期报告重试 |
| WSS `/sessions/{id}/stream` | 实时语音/文本事件，与 HTTP 共享权限和业务逻辑 |

依赖配置、确认材料、知识/题库、LLM/ASR/TTS适配器与持久job；实时语音为首版主线，镜头与代码为可选能力，报告在面后异步生成。文本替代可独立使用；资源所有权不能由模型内容或事件字段授予。

## 5. 边界与合成例

合成学生小周说“团队做了 Redis 缓存，我负责查询接口”。面试官问“你的接口怎样读取缓存，未命中怎样处理？”，不问“你独立设计一致性方案时提升了多少吞吐”。小周说明缓存失效由队友实现后，不再要求编造个人职责；可问他如何理解接口与缓存边界。面后分别指出首答和追问后已补充的内容。

跳过或沉默不直接评低分，未回答部分标未观察；长时间无输入提供继续/跳过/结束，不能推断焦虑。断线先暂停生成，恢复前检查服务端状态；不可恢复时保留确认记录和 failed 终态。有答案但报告失败只重试报告，无答案不生成能力分。

## 6. 验收与优先级

- 正常链路、题号/追问关系、目标时长与 12 分钟安全上限一致，暂停不能无限延长。
- 无参考答案/即时评分，解释题意不转教学；原图右侧数据转到面后分析重点区。
- 合成课设/比赛/科研/少量实习追问贴材料，不夸大个人贡献或补商业指标。
- 重复提交和结束各只产生一次业务结果，后续生成失败不丢已保存回答。
- 取消迟到、断线恢复、转写更正、模型非法输出不污染当前状态/报告。

阶段 A：双栏会话、状态/记录、追问、异步报告和重练，文本联调为过渡。阶段 B：首版核心实时语音、端点/误截恢复、基础语音与可选镜头观测。阶段 C：相关性、事实边界与表达反馈对照验证；3D后续另评。关联：[语音](06-voice-and-speech.md) · [报告](07-feedback-report.md) · [评测](../../algorithm/evaluation.md)。
