# 09｜内容维护与运行管理

版本：v0.2 · 日期：2026-10-15 · 状态：待实现、待验证。

## 1. 目标与范围

2026-10-19 增补：当前已建立[结构化岗位内容库](../../../content/README.md)，包含来源索引、模板/问题版本、首稿归档和结构校验/到期复核清单。实际审核身份、后台页面、数据库和索引任务仍未接入；本轮是公开资料交叉核对与平台原创整理，不代表完成专家校准。

维护技术岗位知识、学生项目问题、评分标准和事实边界，并能定位解析、会话、语音、报告及代码服务故障。首版为团队受限维护能力，可先用授权脚本，不建设教师管理、人才筛选或学生监控系统。

维护权限不自动获得学生原始简历、回答、音视频和复盘媒体。内容质检优先使用合成课设、比赛、科研、毕设和少量实习样例；真实材料的研究/人工质检需要单独明确授权，排障角色不等同研究许可。

## 2. 内容工作流与数据

流程为“登记来源与适用范围 → 编辑/导入草稿 → 切分/检索预览 → 题目/评分抽检 → 发布新版本”，内容状态 `draft → reviewed → published → retired`。未发布或撤回内容不进入新检索，回滚只改变新会话默认版本，不原地篡改旧会话依据。

| 对象 | 维护字段和发布要求 |
| --- | --- |
| 岗位知识 | 来源标题/地址、授权、获取/审核日期、适用技术岗位、正文及版本 |
| 项目追问题 | 适用经历类型、题意、个人职责/技术选择/结果依据/岗位关联目标、追问边界与版本 |
| Rubric | 四维 0～100 锚点、observed/not_observed、证据要求、正反样例与版本 |
| 代码题 | 题干、语言、示例/测试版本、参考解依据、执行资源配置版本 |
| 实时与观测配置 | ASR/端点/算法版本、误截恢复、语速/停顿/疑似口头语、音量/音高变化、视觉描述范围、质量规则及验证记录 |
| 竞品研究 | 官方能力事实、用户自述、机会假设分栏；记录模块、日期与来源偏差，不直接变成产品证明 |

评价样例覆盖“团队获奖但个人贡献有限”“本地课设无商业指标”“科研结论有实验限制”“只有少量实习”等情况。个性化优势必须能回到回答和材料，不能奖励虚构商业成绩。

## 3. 技术处理与运行观测

发布内容和索引存 PostgreSQL/pgvector，切分与嵌入由持久 job 执行。岗位/主题/发布状态过滤先限定候选，再检索；来源定位不因向量化丢失。嵌入模型变更需重建可切换索引并抽检，不混用不兼容向量。知识中的指令视为资料，不能成为系统/工具命令。

运行指标包括材料解析、回答自动封存到首段文本、语音端点到可播放、误截/恢复、打断停止、媒体质量/到期清理、会话完成、报告/比较/导出成功、代码队列/执行、取消与费用。每项标时间范围、分母与数据缺口；学生主动结束、主动取消、网络中断、供应商失败、程序故障分别计数。未知用量/价格标未知，不能当零成本。

持久任务采用唯一任务键、领取锁、超时租约与状态检查；外部请求只在预算允许且无成功结果时至多有界重试一次。解析/报告结果提交前复核输入版本和删除状态，防止重试覆盖学生修改、过期评分或复活已删对象。代码任务取消同时终止隔离进程，费用/资源限额在服务端执行。

日志保留脱敏请求、会话/任务标识、阶段、版本、耗时、用量、错误和操作审计，不写完整简历、逐字稿、报告、私有提示或密钥。服务商密钥仅服务端配置；变更服务或密钥后用合成冒烟样例验证。

## 4. 维护接口与权限

内部 `/api/v1/admin` 覆盖内容草稿/预览、审核发布/撤回/回滚、索引任务、脱敏运行指标和失败任务重试，不作为学生公开 API。首版授权脚本和未来页面调用同一服务逻辑；学生/面试 Agent Tools 不能调用发布或运行维护动作。

最小角色为学生（自己的数据）、内容维护者（共享内容）、运行维护者（脱敏指标/任务）；操作审计记录人、时间、对象与版本、动作和结果。协议适配或 MCP 连接不自动授予权限，未来接入仍需审核工具和来源。

保存默认值遵循[数据与接口](../data_and_interfaces.md)：库内简历至主动删除，临时文件自上传起最长24小时；原音视频默认处理后清除，分别显式授权的私有复盘媒体自采集起最长24小时且不进入长期备份。脱敏日志30天、限权业务备份轮换最长30天。删除先撤销在线访问，物理清理目标24小时；备份恢复重放删除清单。期限均为设计默认而非已经实现的保证。

## 5. 故障与合成例

来源不清/授权未知保持草稿；导入或索引失败不能发布半成品，检索不足明确说明，不伪造引用。新版本错误回滚新会话默认并标记影响，旧引用不静默改写。持续 ASR/TTS 故障降级文字，代码服务不可用返回能力状态，不生成假的运行通过。

合成回归发现系统把队友负责的缓存方案算为学生独立贡献，团队登记复现样例，修订事实归属规则和锚点，再跑回归后发布。旧会话继续显示当时版本，必要时说明受影响依据。运行页定位 TTS 取消失败只需脱敏请求与代标识，不需长期保存学生录音。

## 6. 验收与优先级

- 草稿/撤回不召回，发布/回滚保留旧依据和来源；合成事实边界用例通过才发布。
- 任务重复领取、版本变化、删除、租约超时不产生重复当前结果或资料复活。
- 学生不能发布，内容维护不能批量读私有材料，日志无合成敏感全文/密钥。
- 指标分母与故障分类可解释，未知费用不填零，预算到限保护确认记录。
- 索引切换、语音降级、代码超限终止、备份删除重放可验证。

阶段 A：内容/版本/权限、持久任务、基础指标与预算，文本联调为过渡；阶段 B：实时语音、可选镜头质量、端点/误截恢复、派生观测和媒体清理监测；阶段 C：回归及同材料对照。完整CMS、教师看板及商业分析后续。关联：[架构](../architecture.md) · [知识与 Agent](../../algorithm/knowledge_and_agent.md) · [评测](../../algorithm/evaluation.md)。
