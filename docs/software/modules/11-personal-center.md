# 11｜个人中心：记录、简历与偏好

版本：v0.2 · 日期：2026-10-15 · 状态：待实现、待验证。

## 2026-10-19 设计更新

个人中心采用左侧导航：概览 `/me`、简历 `/me/resumes`、面试记录 `/me/interviews`、目标岗位 `/me/saved-jobs`、偏好 `/me/preferences`，替代原三个Tab。旧Tab链接保留跳转兼容。目标岗位区分收藏模板与个人JD，后者维护企业、原文、来源、备注与常用简历。记录增加简历筛选。

当前支持独立文本简历 `/me/resumes/[id]`，包含教育、技能、自我介绍、补充文本及可排序/确认的经历。复制生成独立ID，保存产生版本；切换简历清空旧重点经历。删除本轮库内文本材料及其经历不改写历史会话快照，并清除未来目标关联。此动作不是生产环境的全量隐私清除；全量材料与快照清理仍按未来鉴权、清理任务另行实现。

实际数据限当前标签页，文件上传/解析/下载与云端身份尚未接入。下文文件生命周期和权限是生产目标，最新原型边界见[扩展记录](../prototype/library-expansion.md)。

## 1. 目标与页面结构

用一个个人中心管理面试进度、不同岗位版本的简历和默认偏好。左侧导航或 Tab 为“我的面试记录”“我的简历”“偏好设置”；不再保留独立历史页，首页“查看我的面试记录”和报告保存/回看入口均进入此处。

学生需要找回未完成面试、查看报告状态，并在下次配置时快速选择对应简历。记录自动保存，不能依赖报告页最后点击保存；“保存记录”可用于确认已保存、命名或进入记录列表，不重复创建会话。

## 2. 三个分区行为

| 分区 | 首版行为 |
| --- | --- |
| 面试记录 | 按时间分页，展示岗位、面试类型、实际输入模式、原面试/重练、开始时间、状态、总分及覆盖/报告状态；支持岗位/时间/状态筛选 |
| 我的简历 | 多份 PDF/DOCX 命名、版本、解析/确认状态、默认标记、预览、下载、删除、设默认；可进入候选核对与经历补充 |
| 偏好设置 | 默认交互方式、编辑器主题、默认岗位方向；偏好不改当前会话，设备/方式可经会话设置显式切换并留痕，材料/题型仍冻结；镜头/媒体每场单独授权 |

记录点击按服务端状态路由：draft/ready 进入配置；in_progress/paused 先读剩余安全预算再继续；ending 显示处理中；completed 进入报告的生成/就绪/失败状态；failed 说明中断，有有效回答时可请求部分报告，否则重新开始。超过 12 分钟安全预算不能把旧会话继续为无限面试，需按状态收尾或新建。

总分为空时显示“未评分/未观察/报告生成中”等真实原因，不显示 0。列表只给概要，详情/报告仍逐资源鉴权。重练关联可展开回看原题与比较，来源删除后不显示已删原文。

简历列表只默认展示 library；配置页 temporary 上传默认不入库，个人中心可从当前临时记录显式保存有效文件。默认仅 library+confirmed，删除默认后清空。文件替换产生版本，配置选择明确版本；切换简历不能混合其他来源经历。预览/下载是私有访问，不生成永久公开链接。

## 3. 数据与接口

`UserPreferences` 字段为 interaction_mode、editor_theme、default_job_direction、version。默认interaction_mode=realtime_voice，可改text_fallback；editor_theme=system，岗位未指定。默认选择语音不等于浏览器麦克风授权或自动录音；进入会话仍需主动启用。camera_enabled与review_media_enabled每场默认false，不从旧授权自动开启。

| `/api/v1` 接口 | 职责 |
| --- | --- |
| `GET /history` | 游标分页/筛选，只读当前用户记录及报告/比较摘要 |
| `GET /sessions/{id}`、`GET /sessions/{id}/report` | 权威状态/版本、恢复和报告入口 |
| `DELETE /sessions/{id}` | 显示并确认派生影响后清理记录、快照、报告及比较 |
| `GET/POST /resume-documents` | 库列表/上传，声明名称与 scope |
| `GET/PATCH/DELETE /resume-documents/{id}` | 状态与版本、命名/文件替换、文件清理 |
| `POST /resume-documents/{id}/confirm`、`/set-default`、`/save-to-library` | 确认、合法默认、显式入库 |
| `GET /resume-documents/{id}/preview`、`/download` | 校验归属的私有文件访问 |
| `GET/PATCH /me/preferences` | 当前偏好与 version，局部修改返回新版本 |
| `DELETE /me/data` | 显式清空所有私有材料与记录，账号注销另行说明 |

列表 `{items,next_cursor}`、错误、幂等和保存合同见[数据与接口](../data_and_interfaces.md)。偏好更新版本冲突时重新读取并提示保留/重试用户修改，不能默默覆盖另一端；数据读取失败保留当前输入，不展示其他用户缓存。

## 4. 保存与删除边界

library简历私有保存至主动删除，temporary自上传起最长24小时，原音视频默认临时处理后清除。显式开启的私有复盘媒体自采集起最长24小时，可提前删除；确认经历、原作答轨迹/识别纠错、会话、代码、派生观测与报告保存至主动删除。列表显示文件/媒体到期或已清理状态，报告时间定位不保证仍能回放。

删除文件清理文件/提取稿/缓存，保留独立确认经历并解除源引用，入口明确说明；删除经历则先列关联会话/报告/比较等影响，再按经历级联清理私有快照。删除会话删除其原作答/纠错、报告、导出、代码、音视频观测、复盘媒体与相关比较；重练独立回答按公共规则处理，不保留已删来源全文。单独删除媒体立即撤销播放，已产生派生观测是否保留在操作入口说明。

在线访问撤销立即生效，物理清理目标 24 小时内；限权备份轮换最长 30 天，恢复须重放删除清单。清理任务显示实际状态，不把“已提交删除”说成全部备份瞬间抹除。所有期限仍是待实现设计默认。

## 5. 合成例与验收

合成学生维护“后端实习版”和“算法比赛版”，设后端版为默认。首页选算法方向后，配置仍清楚显示当前默认简历，由学生切到比赛版并确认重点经历，不自动推断切换全部材料。上次中断面试显示“继续”，完成但报告 pending 显示“报告生成中”；默认文件删除后下次配置显示未选简历。

- 记录自动保存，未完成继续、已完成报告、失败部分报告的入口匹配权威状态。
- 列表分数空值、报告生成态、重练关联可解释，不把失败/未评分当零分。
- 库内多简历、版本、默认、预览/下载及临时显式入库工作一致，切换不混材料。
- 偏好仅影响新配置，麦克风仍主动启用，编辑主题可读且刷新后保留。
- 跨用户 ID/缓存/下载均拒绝，删除清理包含派生数据和后台竞态，备份窗口如实说明。
