# 10｜可选代码答题面板

版本：v0.3 · 更新：2026-10-19 · 状态：模块目标设计；原型已覆盖部分交互，真实服务待实现、待验证，真实执行服务选型与隔离能力待核验。

当前演示能力以[扩展实现说明](../prototype/library-expansion.md)为准；代码位置见[工程目录与职责](../repository_structure.md)。

## 1. 目标与交互

让需要代码考核的技术岗位面试在同一会话中展示实现、验证和思路；项目表达面试可关闭此能力。面板嵌入作答区，可展开或弹窗展示，不成为独立必经页面。提供 C++、Python、Java 选择、语法高亮、输入/期望输出/实际输出、运行与正式提交。

题干支持文字、受控代码片段及已授权图片。图片URL来自受权资源服务，不能执行模型生成的任意链接；渲染统一转义/过滤。代码允许编辑草稿，与实时口头回答不可润色替换的规则分开；讨论思路的口头片段仍保留原始轨迹。语言切换保留各语言草稿或提示未保存变化，不能覆盖已正式提交版本，提交/执行状态分别记录。

运行只针对明确提交 revision 与输入，显示队列、执行、超时/错误及逐例结果。正式提交后 Agent 可内部分析边界、复杂度等以选择追问；不必先运行，没运行则清楚说明“未执行”。面试中仅提不泄露答案的问题，详细漏洞点评、改进建议、评分和参考实现均在面后复盘展示。

## 2. 数据与执行结果

| 对象 | 保存内容 |
| --- | --- |
| CodeTask | 会话内分配题、主问题/追问关联、题目/用例版本、支持语言、执行限额配置 |
| CodeSubmission | owner/session/task、language、source_code、revision、正式提交标记与时间 |
| CodeExecution | 提交 revision、输入/用例版本、queued/running/终态、execution_mode、资源用量、各例结果 |
| CodeReview | 提交/执行版本、代码位置与问题、思路点评、证据、标准/模型版本与异步状态 |

API 语言为 cpp/python/java，支持范围和运行时版本由服务能力返回，不在本文绑定未来编译器版本。`execution_mode=real|simulated` 必须显式；succeeded 表示执行任务完成，是否通过在用例结果中分别记录，不能与“全部测试通过”混用。

Agent 评价与执行结果独立。测试通过仅覆盖已执行用例，不保证正确性/安全性；静态点评可以指出候选问题，不得编造编译日志、耗时、内存或通过率。代码能力只有实际被考查且有足够可判断回答才 observed，未启用或无有效作答标 not_observed。

## 3. 隔离、预算与异步处理

Web/网关只保存输入并通过适配器请求隔离执行服务，不能在应用主进程或数据库主机直接运行用户代码。每个任务使用隔离实例、只读基础环境和限额临时目录，禁止访问宿主敏感文件及未经许可网络，限制编译/运行时间、CPU、内存、进程、输出和文件大小。具体阈值由经验证的配置版本提供，客户端和模型不能放宽。

任务唯一键关联提交 revision、测试版本与任务类型，重复运行请求不重复创建同一结果。题干、输入输出、编译错误、代码注释均为不可信资料，不能触发外部工具、SQL 或任意网络调用。自定义输入同样受长度/输出与资源限制。

结束/暂停/取消按活动任务规则请求停止，隔离执行器终止进程并清理临时目录；迟到结果可保留为对应已保存提交的运行记录，但不能覆盖新版代码、触发已结束会话追问或改变终态。报告只取封存输入版本并核对有效性。

尚未接入真实执行器时，运行按钮显示能力不可用并可继续文本/静态评审；未来原型可以显式模拟数据演示，必须让模拟标记在面板和报告中可见，不能将它当真实测试证据。

## 4. 接口与依赖

| `/api/v1` 接口 | 输入与输出 |
| --- | --- |
| `GET /sessions/{id}/code-tasks/{task_id}` | 会话分配题、版本、语言、示例、限额与能力状态 |
| `POST /code-tasks/{task_id}/submissions` | 代码、language、revision/幂等键 → 提交对象 |
| `POST /code-submissions/{id}/runs` | 固定提交 revision、自定义输入? → 独立执行任务 |
| `GET /code-executions/{id}` | 状态、execution_mode、逐例结果、资源与错误 |
| `POST /code-submissions/{id}/submit` | 正式提交、可用 execution ID? → 评审任务 |
| `GET /code-submissions/{id}/review` | 进行中仅评审状态；会话结束后返回提交版本的详细评审与位置依据 |

所有 ID 沿会话检查 owner，题目公开部分与私有提交访问分开。依赖题库/标准、会话、隔离适配器、异步任务及报告；保存/删除与错误规则见[数据与接口](../data_and_interfaces.md)。

## 5. 合成例与异常

合成学生提交去重算法，空数组用例失败。面板展示真实错误或返回值，面试官可询问索引访问在空输入下的行为，详细漏洞解释留到面后。若代码尚未运行，面后 Agent 只能说明“该分支可能在空输入时越界”，不能写“测试通过率 80%”。学生换新 revision 后旧运行回调只对应旧版，不覆盖当前编辑器结果。

编译错误展示受限输出，输出超限截断并标记；无限循环、内存耗尽、子进程及网络尝试由执行限额处理。服务不可用/排队超时保留代码并允许重试，不能让运行失败丢失正式回答。跳过代码题不自动计零分，提前结束报告显示实际覆盖。

## 6. 验收与优先级

- 可选开关、三语言、运行/正式提交、题干/用例区与展开形态完整，关闭时项目面试可独立完成。
- 编译错误、空输入、运行超时/输出超限、正常通过分别返回真实状态，未接服务明确 unavailable。
- 隔离验证禁止跨任务/宿主/网络越界，限额可终止任务；执行失败与 Agent 评审不混淆。
- 面试中详细评审接口只返回状态，不因提前读取而泄露漏洞提示、参考解法或能力评分。
- 幂等、跨用户访问、版本迟到、取消/结束竞态不污染新答案或已封存报告。
- 原型模拟标记保留到报告，删除会话同步清理提交、结果、评审及执行临时数据。

阶段 A 定义接口和文本/代码记录，先完成真实服务隔离验证再启用真实运行；代码考核是可选首版能力，其服务未达标不阻塞无代码模拟闭环。阶段 C 用可复现边界样例和人工检查验证点评，不宣称执行通过等于掌握代码能力。
