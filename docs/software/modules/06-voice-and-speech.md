# 06｜实时语音与可选镜头表现复盘

版本：v0.2 · 日期：2026-10-15 · 状态：阶段 B 首版核心设计，待实现、待验证。

## 1. 目标与交互

让学生在连续对话中临场组织项目经历、解释技术选择并接住追问。默认 `interaction_mode=realtime_voice`：主动启用麦克风后，听题、思考、直接说、自动保存并自然接话。转写仅为字幕，不以编辑转写后发送作为主线。`text_fallback` 可独立完成，记录实际输入模式，不声称具有相同口语训练条件。

端点检测结合静音、识别稳定性和显式“回答完毕”信号，短暂停顿不立即判答完。学生可以思考、口头自纠、请求澄清、重复问题或打断 AI。误截后可继续口头追加到原回合，保存原片段、新片段和恢复事件，取消依赖旧回答的未完成后续代。AI 主动打断只在学生明确选择相应风格时使用。

摄像头默认关闭，开启需当场授权；无需摄像头也能完成全部专业面试。画面可选小预览，不设置常驻第三栏。面试中只显示采集、识别、播报与设备质量状态，不推送表达点评、能力评分或参考答案；完整语音/镜头反馈由服务端在面后开放。

## 2. 数据与观测口径

| 对象 | 数据与约束 |
| --- | --- |
| AnswerSegment | 原 ASR、片段时间/序号、来源模式、端点、误截追加关系与断流缺口；原轨迹不可润色替换 |
| AsrRevision | 仅面后更正识别错误；保留原识别、更正原因和 revision，不新增观点或事实冒充原话 |
| SpeechObservation | 回答 revision、独立 version、ASR/算法/阈值、metrics、alignment、quality、覆盖与状态 |
| VisionObservation | 对应回答版本、时间区间、画面质量、头部朝向、面部动作、置信与算法版本；质量不足 unavailable |
| ReviewMedia | 分别授权音频/视频、私有定位、授权/媒体版本、到期/删除状态；默认不保留，显式开启自采集起最长 24 小时 |
| 播放进度 | 问题生成代、实际展示文本、音频位置；生成完成不代表学生听到全部问题 |

基础指标采用以下可解释定义，阈值和效果待样本校准：

- **语速：**有效中文字符数/有效发声分钟，排除标点；展示单位、有效时长、排除规则及 ASR 质量，中英混读另检验。
- **停顿：**发声段间候选静音区间、阈值、次数与时长；设备/断线缺口单列，不能据此推断紧张或逻辑差。
- **疑似口头语：**标注“嗯、呃”等及重复连接词的文本/时间位置；“就是、然后”不能无条件判为问题。
- **音量/音高变化：**描述相对变化与时间位置，注明设备增益、距离、环境噪声和清浊音限制；不据此判断情绪、自信或人格。
- **可选镜头表现：**描述可见画面、头部朝向和面部动作候选；缺脸、遮挡、光照差或置信不足标 unavailable，不推断目光动机、诚实、人格、情绪或技术能力。

观测独立于专业知识、项目表达、代码能力、逻辑表达四维总分。纯文本、关摄像头或低质量不会被记零分。建议关联具体回答片段与质量限制，不能把某个动作或单一阈值解释成能力结论。

## 3. 处理、取消与保存

浏览器分片采集 → Node 网关鉴权 → ASR 与端点确认 → 自动封存原作答 → 会话编排 → LLM → 分句 TTS → 有界播放队列。可选视频走独立质量/动作观测任务，不阻塞接话。编码、采样率、视频抽样和分段格式由适配层协商，供应商延迟、中文术语、取消、费用与数据条件均须实测。

前后端共同维护有效generation。打断先停本地播放、清队列，再取消服务端代；旧文本/音频不得重新展示。暂停、关闭和离开页面停止采集与播放；断线保存已收妥片段和缺口，重连重新鉴权、读取权威状态，不盲目补发全部帧。finish或12分钟安全上限优先于重连与迟到观测，未完成片段不静默当完整有效回答评分。

运行设置经 `PATCH /sessions/{id}/interaction-settings` 或 `session.interaction.settings` 统一处理：可切text_fallback、关闭/分别重新授权镜头或媒体保存，携version、原因和授权版本。服务端返回 `session.interaction.updated` 并保留事件；关闭立即停对应采集/写入，使旧capture generation失效并丢迟到帧。重新授权只处理后续片段，不延长已有媒体期限；关闭媒体保存不影响必要临时识别，删除已有媒体另有明确入口。

默认原音视频只作临时处理，完成后清除。开启 `review_media_enabled` 时，音频/视频须分别说明并授权，私有保留自采集起最长 24 小时，可提前删除；媒体不进入长期备份。时间定位、派生观测可以保留，但媒体过期后显示“原媒体不可用”，不能伪造回听或重算。无原媒体且无可靠对齐时相关指标标过期或不可用。

## 4. 接口与依赖

WSS `/api/v1/sessions/{id}/stream` 信封含 session/turn/generation/seq。客户端事件包含 `audio.input/audio.input.end/user.answer.commit/user.answer.append/video.input/video.input.end/user.interrupt/audio.playback.progress/session.interaction.settings/session.finish`；服务端包含 `transcript.partial/transcript.final/answer.endpoint.candidate/answer.committed/answer.appended/input.gap/assistant.text.delta/audio.chunk/assistant.cancelled/session.state/session.interaction.updated/speech.observation.updated/vision.observation.updated/media.state/error`。端点自动提交与HTTP共用权限、版本和幂等服务。

HTTP 提供 speech-observations、vision-observations、review-media 读取、有效媒体私有播放/删除和受限重算。HTTP 与 WS 在进行中仅返回处理状态及设备/采集质量，不返回表达点评或完整指标；所属会话 completed/failed 后开放完整观测。会话中 PATCH 不接受口头答案润色，面后仅受理带原因的 ASR 识别纠错。完整字段与时机限制以[数据与接口](../data_and_interfaces.md)为准。

依赖 ASR/TTS、端点检测、会话、可选视觉适配、派生计算和报告。ASR/视频失败按片段标质量并提供文本替代；TTS 失败保留题目文字。静态状态足以表达倾听/处理/播报，不要求 3D 或写实数字人。

## 5. 合成例与验收

学生说“缓存未命中时查 MySQL”，识别为“My sequel”：原识别随轨迹保存，面后可更正 ASR 并写明原因；报告按明确版本更新，不把识别错误评价成知识错误。学生说“我做了缓存……准确说我只做查询接口”，口头自纠完整保留，不剪掉前句来制造流畅原话。

学生思考停顿后继续，端点候选应撤销；误截则追加回原问题并取消过早追问。镜头遮挡与设备卡顿分别标低质量/采集缺口，不形成“回避目光”“不自信”等结论。关闭摄像头仍获得相同专业评分规则。

- 主动授权才采集，结束/离开/撤销权限正确释放资源；文本替代能独立完成。
- 自动端点、思考停顿、口头自纠、澄清、打断和误截恢复均保留真实轨迹；不提供润色发送。
- 原识别/面后纠错/报告版本分离，重复事件不重复回答；低置信不生成虚构指标。
- 原媒体过期/删除不可播放或重算，媒体鉴权、授权版本、到期任务与删除竞态可验证。
- 分别测端点至接话延迟、误截率、误截恢复、打断到停止、识别纠错负担及观测准确性。

阶段 A 的文本联调用于过渡闭环；阶段 B 交付实时语音、自然接话、基础语音和可选镜头观测；阶段 C 检验反馈准确性、可用性与重练价值。3D、情绪推断和人格判断不作为当前交付。关联：[模拟面试](05-mock-interview.md) · [报告](07-feedback-report.md) · [评测](../../algorithm/evaluation.md)。
