# 风险管理计划

版本：v0.2 · 日期：2026-10-15 · 状态：设计风险与待验证措施，不代表风险已解决。

## 1. 风险登记与处理

| 风险 | 触发信号 | 处理与验收依据 | 责任角色 |
| --- | --- | --- | --- |
| 设计价值缺少验证 | 功能可用，但学生仍无法解释本人贡献或应对追问 | 按项目表达、实时应答和重练任务验证收益，保留结果与限制 | 产品与需求 |
| 范围膨胀 | 同时承诺 3D、完整情绪识别、全仓分析或长期媒体库 | 聚焦实时项目面试；首版视觉为可选轻量观测，原媒体保存有界；本轮仅文档 | 项目协调 |
| 把经历缺口当能力不足 | 因没有实习、商业收入或上线量而扣分 | 使用课设、竞赛、科研合成样例；未观察独立标记 | AI 与面试内容 |
| 个人贡献或优势被编造 | 将团队奖项归为个人、添加性能或增长数字 | 引用确认材料与回答；缺口提问，不自动补全；事实校验失败不发布 | AI 与面试内容 |
| 评分不稳定或缺依据 | 同样回答分数变化大、引用失配、未观察记零 | 锚点与版本冻结，人工双评校准，汇总只用观察项；不得用于录用预测 | AI、测试与质量 |
| 多简历混用或隐私泄露 | 选 A 简历出现 B 经历、其他用户可下载 | 按归属与版本筛选，快照与下载鉴权，跨账号拒绝测试 | 软件工程 |
| 文件清理误删历史或残留 | 临时到期误删确认经历；主动删经历后快照仍可访问 | 明确文件/经历/会话删除范围，任务失效及备份删除重放演练 | 软件工程 |
| 转写错误影响内容评价 | 技术词误识别；为纠错开放的编辑变成补答或润色 | 实时保存原始作答轨迹；面后识别纠错保留原文/原因/版本，依赖结果过期重算；补答只能另建重练 | AI、软件工程 |
| 端点误截或迟迟不接话 | 思考停顿被截断；自动提交重复；无声状态持续等待 | 结合声学与语义判断，保留端点事件；误截允许追加口头片段，提交幂等；测量误截与接话延迟 | AI、软件工程 |
| 停顿或面部动作被心理化 | 系统等待计入卡壳，视线偏移被判无眼神交流，给出紧张/人格结论 | 只描述有效音视频中的观测及质量；语音与视觉独立于专业总分，不推断情绪、诚实或能力 | AI、测试与质量 |
| 镜头质量差或未获许可 | 遮挡、弱光、未检出人脸；关闭摄像头后继续采集 | 默认关闭，拒绝不阻断面试；低质量显示不可观测，关闭立即停采集并丢弃在途数据 | 软件工程、测试与质量 |
| 复盘媒体到期或泄露 | 片段可定位但原媒体已清除；过期链接仍可回放 | 明确选择后仅保存后续片段，每段自采集起私有最长 24 小时，重试不延长；到期撤销访问并清理，派生观测不伪装成仍可回放/重算 | 软件工程 |
| 语音不可用或延迟过高 | 拒绝权限、弱网、迟到音频、无法打断 | 保留文字降级并标实际作答方式，取消代过滤，缓冲与重试有界；系统故障不归为学生能力不足 | 软件工程 |
| 用户代码影响主服务 | 执行无超时、可访问密钥或网络、资源耗尽 | 隔离执行、限时/内存/输出/并发、禁默认外网；未接服务时标明演示 | 软件工程 |
| 供应商费用或依赖失控 | 重复请求、无限追问/重试、服务不可达 | 幂等、预算上限、适配层、测实账；服务商和价格实现前核验 | 项目协调、软件工程 |
| 原型误装为真实能力 | 示例分数/转写/运行结果无标记 | 显示 Mock 演示标识；每项功能按真实服务验收再移除标识 | 产品、测试与质量 |
| 公开评价误作实证 | 官网好评当访谈，企业培训评论代表学生 | 调研记录来源、日期、模块、激励与偏差，不预设胜过竞品 | 产品与需求 |

## 2. 复核与关闭

每次需求变更、阶段进入和服务接入时复核本表。记录风险是否发生、影响、措施、验证证据及剩余风险；通过测试不等于长期不存在。涉及供应商、预算、负责人或日期的未知项保持待确认。

发现权限越界、事实编造、执行隔离失效或删除后复活等严重问题，先停止相关功能的扩大试用并定位修复；已确认文本可安全保留时提供替代路径，不把任务失败伪装成成功。
