## 当前阶段与后续顺序

当前已完成原型和接口骨架，后续真实服务按[评测方案](../algorithm/evaluation.md)的门槛推进：

| 阶段 | 交付目标 | 进入下一阶段的条件 |
| --- | --- | --- |
| 文档 v0.2 | 教师六行模板、需求/用户故事、六界面、接口、Agent、调研、评测与沟通风险计划 | 链接及重要章节、范围和公共合同一致，独立审阅完成 |
| A 基础闭环与文本联调 | 用明确标注的 Mock 数据验证原型，再接身份、材料、模拟、报告、重练和记录；文本联调是实现过渡，代码可选 | 完整流程、权限、事实引用、恢复和删除验收通过；真实代码执行另过隔离限额检查 |
| B 实时语音与基础多模态 | 自动接话、口头作答、澄清/打断与误截恢复、文字降级、语音节奏、可选镜头表现及片段复盘，属于首版核心目标 | 目标网络下记录端点质量与接话延迟，取消/纠错/恢复、媒体有效期、低质量及观测边界验收通过 |
| C 评测与小规模试用 | 学生项目、实时口语与可编辑文本条件对照、竞品/通用模型同材料对照、人工评阅及费用核对 | 实时交互和观察质量有证据，作答条件明确；记录结果与限制，再决定扩大或调整范围 |

每阶段拆成可验收工作项，再确认负责人、日期和预算；本轮不声称新 Issues 已创建。3D 不作为必需门槛，语气只提供可核对的声学变化，视觉只描述画面、朝向与面部动作；不设置情绪、诚实或人格评分。文本联调完成不代表实时面试已交付。配合[沟通计划](communication_mgmt_plan.md)和[风险计划](risk_mgmt_plan.md)维护决策与依赖，不作未经确认的工期承诺。
