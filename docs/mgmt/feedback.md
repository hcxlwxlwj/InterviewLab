## 记录模板

收到真实回复后复制并填写一条，不以预设回答替代老师意见。

| 字段 | 内容 |
| --- | --- |
| 反馈日期、反馈人 | 待实际回复后填写 |
| 来源 Issue / 评论链接 | 待填写真实链接 |
| 原意见摘要 | 基于原文记录，不增添未表达的结论 |
| 团队判断 | 接受 / 需澄清 / 暂缓，以及具体原因 |
| 后续任务、负责人、截止日期 | 链接对应 Issue；成员与日期确认后填写 |
| 修改内容与验证证据 | 修改文件、PR 或验证结果链接 |
| 当前状态 | 待澄清 / 待处理 / 处理中 / 已验收 |
