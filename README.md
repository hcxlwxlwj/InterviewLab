# InterviewLab · 面试练习室

面向大学生和初级求职者的 AI 面试训练产品。计划通过实时中文语音对话和3D 虚拟面试官，帮助用户讲清项目经历、练习行为面试，并完成“练习 → 反馈 → 重练 → 对比”的教学闭环。

> 当前状态：项目初始化与方案验证阶段。本页描述产品规划，功能尚未完成，暂无可运行版本或线上体验地址。技术选型将依据团队能力、实际效果和预算确认。

## 我们希望解决的问题

面试准备不仅是背答案。学生和初级求职者常常难以说明自己的职责、关键行动和结果，也缺少能够根据回答继续追问、提供具体改进建议的练习对象。

InterviewLab 首版聚焦中文项目经历与行为面试，帮助用户发现“哪里没有讲清楚”，并通过针对性重练观察表达的变化。一般沟通训练作为后续扩展方向。

## 计划中的使用流程

1. 选择训练场景，填写岗位要求、项目经历和个人职责。
2. 与 3D 虚拟面试官完成一场 5～10 分钟的中文语音面试。
3. 面试官根据回答动态追问；用户可以打断、请求解释或结束会话。
4. 查看逐字稿与反馈，每项评价尽量引用回答中的具体证据。
5. 选择一个薄弱点进行单题重练，查看前后回答的变化。

模拟面试期间以提问和追问为主，结束后集中反馈；专项训练允许提示与即时指导。

## 首版目标

以下均为待实现目标，而非已上线功能：

- **实时语音**：中文识别、回答结束判断、流式语音播放和用户打断。
- **动态追问**：围绕岗位能力与个人项目经历追问，控制轮数、时长和结束条件。
- **3D 面试官**：首版一位风格化半身角色，支持待机、倾听、思考、说话状态；嘴型跟随实际播放的音频。
- **证据反馈**：引用逐字稿中的原文，提供可执行建议；证据不足时明确提示。
- **重练与对比**：针对一个表达问题重新回答，说明信息与表达结构的变化。
- **记录管理**：保存训练历史，提供删除入口；语音不可用时支持文本继续训练。

首版暂不包含写实视频数字人、摄像头情绪识别、实时算法 IDE、支付或自动投递。

## 拟议技术方案

| 部分 | 当前考虑的方案 |
| --- | --- |
| Web 应用 | Next.js + TypeScript |
| 数据存储 | PostgreSQL |
| 实时对话 | 实时 ASR → LLM → 流式 TTS，服务商通过适配层接入 |
| Agent | 明确状态机，划分面试规划、提问追问、教练评估职责 |
| 3D 角色 | Three.js + VRM / three-vrm，考虑使用 VRoid 制作角色 |
| 部署 | Docker Compose + HTTPS |
| 验证 | 关键流程测试、Agent 离线评测和小规模用户试用 |

先验证中文识别、延迟、打断、弱网表现与完整会话费用，再确定服务商。角色在浏览器渲染，首版使用克制的动作与音频驱动嘴型。

## 开发阶段

1. **基础验证**：验证背景输入、真实模型追问与反馈，打通文本流程。
2. **语音闭环**：完成连续语音、打断、结束与逐轮记录。
3. **角色交互**：加入 3D 角色、字幕、会话状态与音频同步嘴型。
4. **教学闭环**：完善证据反馈、单题重练与前后对比。
5. **发布准备**：验证权限、记录删除、故障恢复、费用限制与可复现部署。

每阶段的具体任务与验收条件通过 GitHub Issues 管理。

## 如何判断产品是否有效

- 追问是否相关、重复率是否可接受、会话能否正常结束。
- 报告引用是否准确，是否出现无依据评价或编造事实。
- 完整训练的延迟、错误率与实际调用费用。
- 用户是否完成练习、愿意重练，以及是否认为建议具体可执行。
- 使用人工评阅和同类新题检验表达改善；不以模型自身评分上涨代替教学效果验证。
