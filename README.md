# InterviewLab · 面试练习室

面向应届生的自主 AI 面试教学产品。计划通过岗位解读、实时中文语音对话和 3D 虚拟面试官，帮助学生理解目标岗位、整理真实经历、练习面试表达，并完成“练习 → 反馈 → 重练 → 对比”的教学闭环。

> 当前状态：项目初始化与方案验证阶段。本页描述产品规划，功能尚未完成，暂无可运行版本或线上体验地址。技术选型将依据团队能力、实际效果和预算确认。

## 我们希望解决的问题

面试准备不仅是背答案。学生和初级求职者常常难以说明自己的职责、关键行动和结果，也缺少能够根据回答继续追问、提供具体改进建议的练习对象。

InterviewLab 首版聚焦中文、跨专业通用面试，覆盖自我介绍、项目/实习/校园经历、行为问题与岗位理解。系统帮助学生发现哪里没有讲清楚、哪些岗位要求还不理解、哪些经历缺少证据，并通过针对性重练观察变化。

## 计划中的使用流程

1. 选择岗位模板或粘贴招聘 JD，理解工作任务与能力要求。
2. 上传简历并确认解析结果，补充项目、实习或校园经历；也可手动填写或进入通用训练。
3. 查看岗位要求与经历的关联，选择教学练习或模拟面试。
4. 与 3D 虚拟面试官完成一场目标为 5～10 分钟的中文语音模拟面试，按回答动态追问；学生可以打断、请求题意解释或结束会话。
5. 查看逐字稿和分维度反馈，依据回答原文提供改进建议。
6. 针对薄弱点单题重练、对比回答，再回顾训练历史。

模拟面试期间以提问和追问为主，结束后集中反馈；专项训练允许提示与即时指导。

## 首版目标

以下均为待实现目标，而非已上线功能：

- **岗位理解**：支持模板与自带 JD，区分明确要求、知识解释与推断。
- **材料与准备**：解析简历并由学生确认，整理真实经历，关联岗位要求与训练主题。
- **教学练习**：允许分步提示、即时解释与专项反馈；示范表达基于已确认事实。
- **实时语音**：中文识别、回答结束判断、流式语音播放和用户打断。
- **动态追问**：围绕岗位能力与个人项目经历追问，控制轮数、时长和结束条件。
- **3D 面试官**：首版一位风格化半身角色，支持待机、倾听、思考、说话状态；嘴型跟随实际播放的音频。
- **证据反馈**：引用逐字稿中的原文，提供可执行建议；证据不足时明确提示。
- **重练与对比**：针对一个表达问题重新回答，说明信息与表达结构的变化。
- **记录管理**：保存训练历史，提供删除入口；语音不可用时支持文本继续训练。

首版暂不包含教师端、班级管理、实时招聘搜索、写实视频数字人、摄像头情绪识别、实时算法 IDE、支付或自动投递。

## 拟议技术方案

| 部分 | 当前考虑的方案 |
| --- | --- |
| Web 应用 | Next.js + TypeScript |
| 数据存储 | PostgreSQL + pgvector；私有文件存储 |
| 实时对话 | 实时 ASR → LLM → 流式 TTS，服务商通过适配层接入 |
| Agent | 确定性会话编排器，按阶段调用岗位顾问、面试官、教练评估职责 |
| 知识与工具 | 已审核知识库、混合检索 RAG、受控内部 Tools；MCP 用于后续外部服务扩展 |
| 3D 角色 | Three.js + VRM / three-vrm，考虑使用 VRoid 制作角色 |
| 部署 | Docker Compose + HTTPS |
| 验证 | 关键流程测试、Agent 离线评测和小规模用户试用 |

先验证中文识别、延迟、打断、弱网表现与完整会话费用，再确定服务商。角色在浏览器渲染，首版使用克制的动作与音频驱动嘴型。

## 开发阶段

1. **文本教学闭环**：打通岗位解读、材料确认、教学/模拟、证据反馈、重练和对比，同时验证权限与删除。
2. **语音闭环**：完成连续语音、确认转写、打断、结束、降级与逐轮记录。
3. **角色交互**：加入 3D 角色、字幕、会话状态与音频同步嘴型。
4. **小规模试用**：验证教学效果、故障恢复、费用限制与可复现部署，依阶段门槛决定是否扩大试用。

各阶段验收、服务商比较与成本估算方法见 [评测与迭代计划](docs/evaluation-and-roadmap.md)。

每阶段的具体任务与验收条件通过 GitHub Issues 管理。

## 如何判断产品是否有效

- 追问是否相关、重复率是否可接受、会话能否正常结束。
- 报告引用是否准确，是否出现无依据评价或编造事实。
- 完整训练的延迟、错误率与实际调用费用。
- 用户是否完成练习、愿意重练，以及是否认为建议具体可执行。
- 使用人工评阅和同类新题检验表达改善；不以模型自身评分上涨代替教学效果验证。
